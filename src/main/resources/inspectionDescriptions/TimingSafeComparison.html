Reports a webhook or HMAC signature comparison done with .equals() or Arrays.equals() instead of MessageDigest.isEqual(...), inside a method that computes an HMAC.

These comparisons stop at the first differing byte, so response times reveal how much of a guessed signature is right, and a valid signature can be rebuilt byte by byte (CWE-208). MessageDigest.isEqual runs in constant time. Signature variables are recognized by name (sig, hmac, hash, digest, mac).
